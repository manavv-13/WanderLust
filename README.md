# Airbnb Listings Management Web App

## 📌 Project Description
Developed a secure web application for managing Airbnb listings, including functionalities to **add, edit, and delete** listings. The application also features an **interactive map** for location display and allows **authenticated users** to leave reviews on other listings.

## 🚀 Features
- **User Authentication**: Secure login/logout functionality.
- **Manage Listings**: Users can add, edit, and delete Airbnb listings.
- **Interactive Map**: Displays Airbnb locations dynamically.
- **Reviews System**: Users can leave and manage reviews on listings.
- **Responsive UI**: Built using Bootstrap for a modern and user-friendly design.

## 🛠 Technologies Used
- **Frontend**: HTML, CSS, JavaScript, Bootstrap
- **Backend**: Node.js, Express
- **Database**: MongoDB
- **Authentication & Security**: Implemented using **Passport.js** for secure user authentication.

## 🔐 Authentication & Security
- Uses **Passport.js** for authentication and session management.
- Implements **session-based authentication**.
- Basic **input validation and sanitization** to prevent security threats.
